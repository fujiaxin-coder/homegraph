# 0027：查询约束与源码片段身份

- 日期：2026-09-08
- 状态：已完成（实现及本地测试；准确率效果未确认）
- 范围：HomeGraph MCP 查询提示、可选的源码片段身份；对应的 Headroom/SDK 接入在独立 codingeval 仓库。

## 背景和行为

保留用户要求的动作、产品/模块范围和约束，提示模型使用返回的仓库相对路径，不通过猜测实验目录读取源码。返回的文件/行号只是候选证据，必须核对是否属于任务目标。

HOMEGRAPH_SOURCE_RECEIPTS=1 时，为 homegraph_node 返回的源码片段附加内容身份，支持分析重复读取和源码变化。片段身份仅标识实际返回的范围，不等同于全文件哈希，不证明整个任务完成。默认不开启附加身份，不改变图查询 schema、索引或检索算法。

Headroom 0.37.0、SDK MCP、模型 HTTP/SSE 代理与逐请求审计由 codingeval 的可选推理优化实现；它们不作为 HomeGraph 的 Python 运行依赖。本仓不携带实验结果、模型凭据或答案缓存。

# 0029 — ArkTS atomic evidence packs

- 类型：设计 / 变更
- 状态：已完成（用户授权先实现最高优先级一批）
- 日期：2026-09-11
- 范围：HomeGraph MCP；独立目录 smat051-evidence-packs-20260911

## 背景与目标

当前 ArkTS explore 已能定位符号和关系，但紧凑摘要可能截断方法、丢掉条件，
或只有关系名称没有两端源码。模型因此继续搜索。第一批将已经检索到的证据按
完整声明及关系依赖选入预算，并明确没有提供什么。目标是减少补查轮次；
不以本地渲染速度或 token 减少冒充真实推理时延提升。

## 行为

1. 复用现有 compact、light mechanism、full explore 的候选节点和静态图；
   在含本地 `.ets` 声明的 compact/light mechanism 和已定位静态链/flow 计划中启用；
   full explore 的字面量/资源证据与专用 usages/modules/native 路由保持原行为。
   不增加 planner / LLM 请求，不新建工具，不以题号或新增关键词规则路由。
2. 证据类型区分完整源码、静态关系、缺口。源码必须来自当前工作树，带路径、
   行范围、指纹。完整声明保留其内部条件和分支，不拼接窗口假装完整函数。
3. 一个关系包依赖两端源码；有独立注册位置时还依赖包含注册位置的完整声明。
   静态边的 kind、provenance 和合成方式可见；不宣称运行时顺序或值传播已证明。
4. 按优先级贪心选择完整包，共享源码不重复输出；预算计算包含标题、行号、
   代码围栏、关系说明和缺口。超过预算的包整体省略，不截断源代码。
5. 未读到、索引过期、超预算、依赖不完整及未索引的连接显式列为 Gap，给出
   具体符号/路径作为下一步定位线索。只声明本次有限检索的覆盖情况。
6. 会话收据只登记实际发送的源码范围。多步 planner 的共享预算也不得截断
   已形成的包或保留与被截断正文不一致的定位收据。
7. 文件读取及候选数量有上限，拒绝越界路径及符号链接逃逸；无法构造声明证据
   时保留成功形状的缺口，不能将 SDK 声明当作本地实现。
8. 过滤 ArkAnalyzer 虚拟入口和隐式构造器；命名成员的所属类型只作为作用域，
   不虚构“类型必须调用方法”的缺口。保留 @Prop / @Link 与事件绑定的图元信息。
9. 缓存格式升级并区分 `HOMEGRAPH_ARKTS_EVIDENCE_PACKS=0` 的消融结果。
   完整包命中缓存前检查已返回文件的指纹；过期/不完整结果重新检索。

默认启用；`HOMEGRAPH_ARKTS_EVIDENCE_PACKS=0` 关闭本批渲染器。开关应在 MCP
进程启动前设定，修改后重启服务。比较开关两组可隔离本批改动；比较 050/051
目录时还包含从上游 main 合入的 1.5.7 路径/索引状态修复。

## 非目标与约束

- codingeval、预建索引与旧版本不变；不上线新的评测结果或性能结论。
- 不实现通用 CFG/数据流、新 ArkUI/NAPI 解析器、向量检索或自动递归检索。
- 不读取隐藏答案、参考 patch、未来提交；合成测试用例独立于 benchmark。
- Headroom 仍由现有外部运行链路接入；本批不把 Python 压缩器移入 MCP，
  不修改 codingeval。证据正文与 `_meta` 维持标准 MCP 格式，源代码不得被
  HomeGraph 自身有损摘要。端到端 Headroom 效果留待原实验链路验证。

## 验收

- [x] 关系与其两端/注册声明共同入选，共用声明只输出一次。
- [x] 未连通、缺失、过期、越界及预算不足不会被标为完整证据。
- [x] 总输出受预算限制，收据与正文一致，多步计划不截断包。
- [x] MCP 实际执行路径、ArkTS 合成图及已有相关回归测试通过。
